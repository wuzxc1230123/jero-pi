# 程序化生成（Godot 4.x）

管"生成是纯函数，引擎只消费"。深度知识住模块 references（L2，路径经模块知识入口注入，按需读）。

> **相关技能：** 瓦片地图消费生成结果 → `godot-tilemap`；RNG 注入与可测性 → `godot-gdscript`；品类配方 → `godot-genres`。

## 何时使用

做随机地图/地牢/物品生成、写噪声采样、排查生成不可复现时使用；手搭关卡归 `godot-tilemap` 管。

## 核心要点

- 铁律：**生成 = 纯函数（种子 → 数据）**——同种子必出同结果；引擎侧只消费数据渲染，不在生成过程里碰场景树。
- 全局 `randi()/randf()` 在 procgen 里**禁用**：一律注入 `RandomNumberGenerator`，`seed = value` 显式定。
- 分层：地图布局（格子/图）→ 玩法语义（可走/伤害/刷怪点）→ 表现（瓦片/装饰）；层间只走数据，调试可以逐层 dump。
- 噪声（FastNoiseLite）参数也是数据：进 Resource 可调可存，不硬编码。
- 分块/流式生成按需扩展，别一次性生成整世界再裁剪。

## 红线

- 生成函数里 new 节点/改场景树（不可测、不可重放）。
- 用全局 RNG（每次运行不同——bug 无法复现，测试随机挂）。
- 生成结果直接覆盖玩家存档语义（生成数据与存档数据分离，见 `godot-save`）。
