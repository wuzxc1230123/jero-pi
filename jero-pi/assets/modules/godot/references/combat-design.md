# 战斗设计（ACT 方法论：招式集 / 元规则 / 反模式 / 参数基线）

设计层方法论，精编自 act-combat-design（MIT）知识库；实现层（技能系统数据
模型 / 反馈代码 / AI 行为树）见本模块 `ability-system.md`、`game-feel.md`、
`game-ai.md`——本篇管"设计什么、为什么这样设计"。

## 约定先行（一切设计的第一步）

**不预设任何战斗体系**：招式集分类、视觉预警语言（什么颜色可闪/可弹）、
受击状态分级、目标帧率、命名规范、有无配队/养成——全部由项目自己的
战斗约定定义，先写约定再做设计。抄"别的项目的九招招式集/红光必闪/
命座"是套用他人体系，不是设计。

## 招式集设计法（类型菜单与各类型手艺）

- **普攻连段**（几乎必备）：3–5 段，起手轻快、中段渐重、**末段最重**
  （击退/击飞做"标点符号"）；每段带少量位移（贴身/空间感）；轻段判定窄、
  重段宽；段数越多越要防中段无聊。
- **蓄力/重击**：拆 **pre（前摇）+ charge（蓄力 loop）+ release + recover**
  四段；档位反馈清晰（音效升调/光效分级/姿态变化）；**蓄力期不能纯等待**
  ——允许移动、允许被完美闪避取消并保留蓄力进度。
- **核心特殊技 = 角色差异化载体**：长按蓄力体 / 资源满替换强化版 /
  变形态触发 / 短长按二分 / 持续 loop 五种形态，与角色原型挂钩选一。
- **闪避三层**：基础位移 → 闪避攻击 → 完美闪避反击（短距推进 + 强控制）；
  "闪避取消蓄力保留资源"是给高手的隐藏操作空间。
- **防反/格挡**：弹反对撞拆 **start（判定窗）+ success + attack + end**；
  先对齐预警契约（什么可格/可弹）再设计；地面/空中是否各一套取决于
  项目有无空战，别无脑双套。
- **空攻**：下劈/下砸/水平扫射，落地常带 AOE。
- **大招**：前摇给警示、打击给爽感、后摇别长；自身能量满触发，与团队
  联动技（后台/团队能量）区分。
- **团队联动技**：仅团队制项目需要，形态由配队模型决定。

## 元规则精选（思维内核）

- **差异化在"操作动词"层，不在数值层**——同是"砍"，蓄力/弹反/变身才是差异。
- **资源条 = 玩家机制识别 UI**：一看条就知道这角色怎么玩。
- **化学反应 = 决策深度上限**：技能间互动比技能数量值钱。
- **Pressure → Stagger → 倍率窗口三段式** 优于纯 HP 阶段化（压制积累 →
  击破 → 输出窗口，玩家有节奏目标）。
- **单角色机制变量 ≤ 2 个核心锚点**：第三个机制就开始稀释辨识度。
- **决策密度节拍（30 秒法则）**：任意 30 秒窗口内玩家至少有一次非平凡选择。
- **行为克制 > 属性克制**；**闪避奖励给战略价值**（资源/位势），不只是无敌帧。
- **机制即定位 + 独家机制 UI 可见化**：对手也能看懂的机制才有传播度。
- **Snapshot vs Dynamic 是 buff 设计的隐藏发动机**（快照结算 vs 动态结算
  决定配队深度）。
- **招式 IP 化命名**：不要"普攻 1/2"——名字是记忆点的一部分。

## 打击感设计参数基线（5 攻击类型，设计目标值）

| 维度 | 轻击 | 中击 | 重击 | 暴击 | 必杀 |
| --- | --- | --- | --- | --- | --- |
| Hit-Stop | 2–3f | 4–5f | 6–8f | 8–12f+微缩 | 12–20f+全屏闪光 |
| 震动强度 | 0.1–0.2 | 0.2–0.35 | 0.35–0.55 | 0.55–0.75 | 0.75–1.0 |
| VFX 层数 | 2 | 3 | 4 | 5 | 6–10 专属 |
| 屏幕泛白 | 无 | 无 | 可选 | 必须 2–3f | 必须+持续微泛色 |

弹反成功：4–6f 对等顿帧 + 高频锐利音 + 短脉冲振动——反馈要对等来袭强度。
实现落地（trauma 模型/层级开关）见 `game-feel.md`。

## 数值与配队（概览）

- 伤害公式先定架构哲学（纯乘法 bucket / 韧性折扣双层 / 双赛道），公式
  决定"堆什么属性"的玩家心智；击破系统配积累公式与全队倍率窗口。
- 配队：**一支神队 = 一个 win condition + 三角色围绕它**；3D ACT 最稳
  模板 Driver + Sub-DPS + Support×2；**"脱手"（后台持续贡献）是配队灵魂**；
  Combo 设计按 T-1 → T+0 → T+N 三段节奏。

## NEVER（反模式自检，精选）

- **NEVER 单一机制收益过高**——其他玩法全体贬值。
- **NEVER 蓄力期玩家无操作**（纯等待）或大招长且不可被打断（节奏停滞）。
- **NEVER 召唤物太强**——玩家失去主导感。
- **NEVER 全屏 AOE 无躲位**（不公平）或 telegraph 模糊逼玩家背板。
- **NEVER 机制堆砌学不动**；单角色机制锚点 ≤2。
- **NEVER 无视觉记忆点**：姿态五米外可辨识、招式有 IP 名，平庸即失败。
