# 对话与叙事（Godot 4.x）

管"对话是数据问题，不是脚本问题"。深度知识住模块 references（L2，路径经模块知识入口注入，按需读）。

> **相关技能：** 数据层 Resource 化 → `godot-resources`；对话 UI 呈现 → `godot-ui`；打字机效果等演出 → `godot-animation`。

## 何时使用

做对话/剧情/分支选项系统、设计对话数据结构时使用；对话框的布局与焦点归 `godot-ui` 管。

## 核心要点

- 台词/选项/条件全部 `Resource` 化（`DialogueLine`/`DialogueChoice` 自定义类型），运行时引擎只做**取数 + 呈现 + 记账**三件事。
- 分支走数据（选项 → 下一条 ID），不走代码 `if` 链——加剧情 = 加数据。
- 条件与变量分层：世界状态（好感度/旗标）是对话系统外的独立数据面，对话定义只**引用**变量名，不内嵌逻辑。
- 文案本地化预留：文案键与展示分离，硬编码中文串集中在数据层。

## 红线

- 对话流程写成巨型 `if/elif` 或状态机（改一句文案要动代码）。
- 对话数据里内嵌可执行表达式/逻辑（策划资产变代码注入面）。
- 呈现层直连数据内部结构（中间隔一个"当前对话状态"视图，换 UI 不换数据）。
