# 表单（Vue 3）

表单是状态与信任边界的中点：客户端校验是体验、服务端校验是权威；v-model 是语法糖不是数据流豁免。

> **相关技能：** 组件双绑契约 → `vue-components`；防抖工具 → `vue-vueuse`；服务端校验权威 → `vue-nuxt`。

## 何时使用

设计/评审表单状态与校验、封装表单控件组件、处理提交竞态时使用。

## 核心要点

- **v-model 修饰符**：`.lazy`（change 才同步，减少中间态）、`.number`（数值归一——空串变空而非 0 要防）、`.trim`（去空白）——按语义选不是全加。
- **控件组件化**：输入组件用 `defineModel()` 双绑（`vue-components` 契约）；受控面单值 prop + 事件，不自藏内部状态导致外部重置无效。
- **校验分层**：客户端（VeeValidate/自写规则）管即时反馈与必填提示；**服务端重校验一切**（提交动作的权威判定在服务端——客户端规则只是体验）；错误回传字段级结构（`{ field: message }`）映射回表单。
- **校验时机**：失焦/变更/提交三档按字段语义选；提交后整体校验显示全部；异步校验（用户名查重）防抖 + 取消竞态（`watchDebounced` + AbortController）。
- **动态表单**：schema 驱动（字段配置数组渲染）优于手写条件模板爆炸；嵌套字段名与提交结构对齐（平铺 ↔ 嵌套转换收在一处）。
- **提交纪律**：提交中禁用按钮防重复；失败可重试（错误态可清理）；离开未保存表单 `beforeRouteLeave`/`onBeforeRouteLeave` 拦截。

## 红线

- 只信客户端校验（绕过 UI 直打接口即穿）。
- 提交无防重复（双击双单）。
- 表单状态与 store 双源（表单本地态完成后再提交入库）。
